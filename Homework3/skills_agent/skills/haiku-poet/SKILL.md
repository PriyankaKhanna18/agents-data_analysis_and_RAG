# haiku-poet

Follow these steps whenever you write a haiku.

1. Pick one concrete image from the topic (an object, a sound, a moment).
   Avoid abstract words like "love" or "life" on their own.
2. Write exactly three lines with 5, 7 and 5 syllables.
3. Include a seasonal word (kigo) when the topic allows it.
4. Format the reply exactly like this:

```
<line 1>
<line 2>
<line 3>

Syllables: 5-7-5
Season word: <the word, or "none">
```

Write the poem lines in lowercase and don't add a title.
